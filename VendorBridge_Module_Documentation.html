VendorBridge ERP — Module Functionality Documentation

Detailed breakdown of all 10 side panel modules  |  VendorBridge Enterprise Resource Planning System v3.1

1 Dashboard

The Dashboard is the central landing screen after sign-in. It gives a real-time overview of the entire procurement operation in one view.

Key Functionalities

  • Welcome Banner: Displays a personalised greeting with the logged-in user's name and today's procurement status. Provides quick-action buttons to view recent invoices, view open purchase orders, and create a new RFQ directly.
  • KPI Summary Cards (4 cards):
    • Pending Approvals – count with percentage trend indicator.
    • Active RFQs – count with an "in progress" status badge.
    • Open Purchase Orders – total monetary value in INR.
    • Invoices Sent – count with a clearance status indicator.
  • Top Vendors by Spending Table: Lists the highest-spend vendors with their spending amount, activity status (Active / Pending / Closed), and star rating (1–5).
  • Analytics Bar Chart: Quarterly comparison chart (Q1–Q3) with two bar series — Services (grey) and Goods (purple/teal) — with a colour-coded legend.
  • Recent Activity Feed: Live feed of the latest procurement events (RFQ created, PO issued, invoice approved etc.) with timestamps.
  • Global Search: Top-bar search that filters searchable elements across the page in real time.
  • Add New Button: Sidebar shortcut button that navigates directly to the Add Vendor flow.

2 Vendors

The Vendors module is the central directory for all supplier profiles registered in the system.

Key Functionalities

  • Vendor Table: Displays all registered vendors with columns for Vendor ID, Vendor Name, Category, Contact (email + phone), Location, Status, and Actions.
  • Status Badges: Each vendor row shows a colour-coded status — Active (green), Pending (amber), or Inactive (grey).
  • Filter Toolbar:
    • Filter by Status (All / Active / Pending / Inactive).
    • Filter by Category (Hardware Components, Software Licenses, Professional Services, Logistics & Shipping).
    • Live search box to find vendors by name.
  • View & Edit Actions: Each vendor row has a View (eye) icon to see full details and an Edit (pencil) icon to modify the record. Both trigger toast notifications.
  • Register New Vendor Modal: Clicking "Add Vendor" opens a modal form with fields for Vendor Name, Category, GST Number, Contact Person, Email, Phone, Website URL, and Address. Submitting registers the vendor and adds them to the table.
  • Vendor Registered Confirmation: On successful registration, a success toast appears with the new vendor's name and their auto-generated Vendor ID.

3 RFQs (Request for Quotation)

The RFQ module allows procurement managers to create and send structured requests for quotation to one or more vendors through a guided multi-step form.

Key Functionalities

  • 4-Step Stepper Wizard: The form is split into four sequential steps with a visual progress rail on the left:
    1. Basic Information – RFQ Name, Project/Cost Centre, Description & Requirements (with rich-text toolbar for bold, italic, underline, lists, links), and a Line Items table.
    2. Attachments – Drag-and-drop file upload zone for supporting documents. Supports multiple file types with file chip previews and remove buttons.
    3. Assign Vendors – Select which registered vendors should receive the RFQ.
    4. Deadline Selection – Set response deadline, priority level (Low / Medium / High via pill radio buttons), and submission type toggle (Open / Sealed).
  • Line Items Table: Add/remove line items with fields for Product/Service name, Description, Quantity, Estimated Unit Price, and auto-calculated Estimated Total per row.
  • Priority Radio Pills: Colour-coded priority selection — Low (neutral), Medium (amber), High (red).
  • Save Draft: Saves the current state without submitting. Shows a success toast.
  • Save & Continue / Submit RFQ: Navigates through steps; on the final step submits and sends the RFQ to assigned vendors.
  • Cancel: Discards the form with a confirmation prompt.
  • Breadcrumb Navigation: Shows current path (RFQs > Create New).

4 Quotations (Submit Quote)

The Quotations module is used by vendors (or on behalf of vendors) to submit pricing responses against an active RFQ.

Key Functionalities

  • RFQ Identity Strip: A persistent banner showing the RFQ name, a live countdown timer to the closing deadline (shown in red), and quick-access Save as Draft and Submit Quote buttons.
  • Line Items & Pricing Table (Left Column):
    • Displays each item requirement from the original RFQ with Quantity, Unit of Measure (UOM), and the buyer's Expected Price.
    • Vendors enter their Submitted Unit Price in an editable blue input field per row.
    • Total Line Price is auto-calculated as quantity × submitted unit price.
    • Rows can be deleted individually.
  • Terms & Conditions Section:
    • Delivery Date picker.
    • Quote Validity toggle (30 / 60 / 90 days).
    • Notes / Special Conditions free-text area.
  • Quote Summary Card (Right Column, sticky): Auto-updating breakdown showing Subtotal, Estimated Tax, and Grand Total (in INR). Contains the primary "Submit Quote" CTA button and a secondary "Save as Draft" button.
  • Submit Confirmation Modal: Before final submission, a modal asks for confirmation showing the vendor name, total quote value, and a binding notice.
  • Live Countdown Timer: JavaScript-driven timer that counts down to the RFQ closing date and updates in real time.

5 Comparison

The Comparison module provides a side-by-side evaluation of all vendor quotations received for a specific RFQ, enabling data-driven supplier selection.

Key Functionalities

  • Summary Statistics Bar: Shows at a glance — number of Quotations Received, Lowest Bid (vendor + amount), Price Range (spread between min and max bids), Average Delivery time, and the System-Recommended vendor.
  • Side-by-Side Comparison Table: Vendors are displayed as columns, criteria as rows:
    • Total Price – lowest bid highlighted in green with a "Lowest" badge; higher bids shown in grey.
    • Delivery Timeline – fastest shown in normal weight; slowest shown in amber with a "Slowest" warning tag.
    • Vendor Rating – star rating display with numeric score.
    • Expandable Sub-rows – clicking "Show details" expands per-item pricing breakdown.
  • Recommended Vendor Highlight: The system-recommended vendor column is visually highlighted in a light blue tint with a "Recommended" pill badge.
  • Filter & Sort Panel: Collapsible panel with Sort By (Price, Timeline, Rating, Name), Filter Vendors checkboxes, and Expand All toggle.
  • Award Vendor Action: Button to officially award the contract to the selected vendor, triggering a confirmation modal.
  • Export Report: Downloads the comparison data as a report.
  • View Documents Modal: Opens a modal to preview supporting documents submitted by a vendor.

6 Approvals

The Approvals module manages the internal sign-off workflow for procurement requests before a Purchase Order is issued.

Key Functionalities

  • Request Identity Banner: Displays the Request ID, current status (e.g. "Pending Manager Approval" in amber), the request title, and the total value of the procurement request in INR.
  • Request Details Card (Left): Full metadata grid showing Vendor, Requested By (with user avatar), Department, Date Submitted, Cost Centre, Budget Code, and Priority pill (High/Medium/Low).
  • Line Items Sub-table: Itemised list of what is being procured with SKU codes, quantities, unit prices, and row totals, plus a grand total footer row.
  • Approval Timeline Stepper (Centre): Visual vertical stepper showing the full approval chain — completed steps (green checkmark), the current active step (blue dot), and future pending steps (grey circle).
  • Action Panel with Tabs (Right):
    • Decision Tab: Remarks textarea (required), and three action buttons — Approve (green), Reject (red), Request Clarification (neutral).
    • Notes Tab: Threaded notes between approvers with user avatars, timestamps, and an input field to add new notes.
    • History Tab: Log of all previous actions taken on this request with status pills (Approved, Submitted etc.).
  • Confirmation Modal: Any approval/rejection action triggers a confirmation modal before the decision is committed.
  • Decision Banner: After actioning, a colour-coded decision banner (green for approved, red for rejected, blue for clarification) appears above the action panel.
  • Search: Top-bar search to find approval requests by keyword.

7 Purchase Orders

The Purchase Orders module generates, displays, and manages official PO documents issued to vendors after approval.

Key Functionalities

  • PO Document View: A formal, print-ready Purchase Order document with a branded header (gradient blue VendorBridge stamp with PO number).
  • Vendor & Buyer Details: Two-column layout showing full company name, address, email, and phone for both the Vendor and the Buyer (Bill To / Ship To).
  • PO Metadata Strip: PO Number, Issue Date, Expected Delivery Date, and Payment Terms displayed in a 4-column grid below the address block.
  • Line Items Table: Numbered rows with Item Description (name + part/spec detail), Quantity, Unit Price, and Total per line.
  • Special Instructions Block: A read-only text area displaying any special instructions attached to the PO (e.g. delivery preferences, compliance requirements).
  • Financial Summary: Subtotal, Tax (GST), Shipping, and Grand Total in a structured summary block.
  • Signature Block: Authorised signatory line with name, title, and date fields.
  • Action Buttons: Print PO, Download PDF, Print Invoice, and Send Email (opens a compose modal with recipient, subject, message body, and attach PO toggle).
  • Search: Inline search to filter line items on large POs.

8 Invoices

The Invoices module mirrors the Purchase Order view but is oriented toward invoice management and payment processing.

Key Functionalities

  • Invoice Document View: Displays the same PO document structure re-branded as an Invoice, with all line items, vendor and buyer details, and financial summary.
  • Status Badge: Shows current invoice status — "Approved & Issued" in green.
  • Action Buttons: Print PO, Download PDF, Print Invoice, and Send Email (identical to Purchase Orders module with full email compose modal).
  • Send Email Modal: Compose window with To address, Subject line, Message body, and a checkbox to attach the PO/Invoice document as a file chip.
  • Line Item Search: Inline search to filter invoice line items.
  • Financial Summary: Subtotal, Tax, Shipping/Handling, and Grand Total breakdown.
  • Signature Block: Authorised signatory fields for name, title, and date.
  • Print Styles: Sidebar, topbar, and action buttons are hidden when printing, producing a clean invoice document.

9 Reports & Analytics

The Reports & Analytics module provides a comprehensive data intelligence layer for procurement performance monitoring and auditing.

Key Functionalities

  • 5 KPI Summary Cards:
    • Total Spend (Month-to-Date) with percentage trend vs. last month.
    • Active RFQs count with weekly closing count.
    • PO Fulfilment Rate (%) with trend indicator.
    • Registered Vendors count with pending verification badge.
    • Average Approval Time (days) with improvement trend.
  • Monthly Procurement Spending Chart: Side-by-side bar chart (Jan–Jun) comparing Purchase Orders vs. Invoices Paid per month. Supports Bar / Line / Area toggle views.
  • Spending by Category Donut Chart: Visual donut chart breaking spend into Hardware (34%), Services (28%), Logistics (22%), Software (16%) with a legend.
  • Vendor Performance Rankings Table: Ranked table of vendors with columns for Rank, Vendor Name, Category badge, Total Spend, Number of Orders, Star Rating, and Performance label (Excellent / Good / Needs Improvement). Searchable and sortable by Performance Score or Spend.
  • Procurement Funnel Chart: Horizontal funnel showing the procurement pipeline stages — RFQs Sent → Quotes Received → Shortlisted → Approved → PO Issued — with stage-by-stage counts and colour graduation.
  • Compliance Score Gauge: Semi-circular gauge chart showing overall compliance health score (e.g. 73%).
  • Date Range Filter: "Last 30 Days" selector in the topbar to adjust the reporting period.
  • Export Report: Button to trigger an export modal with options for format (PDF, Excel, CSV) and report scope selection.

10 Activity (Audit Logs)

The Activity module is a full system audit trail that records every procurement action, state change, and user interaction across all modules.

Key Functionalities

  • Activity Stats Strip (5 chips): At-a-glance count of today's events by type — Created, Approved, Rejected, Updated, and Auto-Generated — each with a colour-coded icon.
  • Filter & Search Toolbar:
    • Filter by Action Type (Created, Approved, Rejected, Updated, Deleted, Uploaded, Auto-Generated).
    • Search by User name.
    • Date Range filter (From and To date pickers).
    • Apply Filters and Clear buttons.
  • Chronological Log Feed: Scrollable list of all system events grouped by date (Today, Yesterday, etc.) with date-divider labels. Each log entry shows:
    • Colour-coded event icon (blue = created, green = approved, red = rejected/deleted, amber = updated, purple = auto-generated, indigo = uploaded).
    • Human-readable action description with the actor's name highlighted, action verb, and the target entity ID (e.g. RFQ-2023-045, PO-2023-2329).
    • Action Type tag pill (colour-coded label).
    • Timestamp.
    • Expandable sub-detail on click (shows additional context such as previous value, new value, or comment).
  • Load More: A "Load More" button at the bottom of the feed to paginate additional log entries.
  • Export: Export the audit log as CSV or PDF for compliance and audit purposes.
  • Notification Bell (Topbar): Bell icon with a red unread badge. Clicking opens a dropdown notification panel showing the latest system notifications with mark-all-as-read and view-all links.
  • Global Search: Searches logs by event description, user name, or event ID in real time.
